# Test Report Templates

## 목적

이 문서는 테스트 결과를 길고 소모적인 로그 대신, 빠르게 판단 가능한 형식으로 보고하기 위한 템플릿 모음이다.

원칙:

- 로그 전문보다 판단 가능한 요약을 우선한다.
- 실패가 없으면 간결하게 쓴다.
- 실패가 있으면 재현 조건, 영향 범위, 다음 액션을 함께 적는다.
